RailSaathi API

Indian Railway Local Passenger & Hawker Commerce Backend Engine

API Endpoints

  • GET /api/health
    System health, DB status & timestamp
  • GET /api/stations/search?q=SDAH
    Search stations (Live + Fallback cache)
  • GET /api/stations/:code/trains
    Station departure board & train candidate list
  • GET /api/trains/:number/live
    Real-time train running status & GPS tracker
  • POST /api/requests
    Broadcast hunger signal & food order request
  • PATCH /api/orders/:id/price
    Vendor price offer & quote submission
  • PATCH /api/orders/:id/confirm
    Passenger confirmation & acceptance
  • POST /api/orders/:id/complete
    Complete delivery & record cash collection
  • POST /api/sync
    Idempotent offline batch sync queue
